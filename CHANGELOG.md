# Changelog

All notable changes to GAMEOPZ will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-27

### Added
- Initial project setup
- Backend scaffolding with Express.js and MongoDB
- Frontend setup with Next.js and React
- Docker configuration for local development
- Database schema design for games, users, reviews, and discussions
- GitHub Actions CI/CD pipeline
- Contributing guidelines
- API documentation structure

### Future Planned Features
- User authentication and authorization
- Game database CRUD operations
- Review submission and management
- Rating system
- User profiles and followers system
- Discussion forums
- Search and filtering functionality
- Admin dashboard
- Email notifications
- Social features (sharing, recommendations)
